# VibeFlow Hero

Создайте Hero-секцию для лендинга-портфолио специалиста по вайбкодингу. Используйте визуальный стиль, цветовую палитру и композиционные решения загруженного референса. Используйте темную цветовую схему с акцентными неоновыми элементами.

Основной заголовок: Создаю AI-продукты с помощью вайбкодирования.

Подзаголовок: Быстро собираю MVP, лендинги и веб-приложения с помощью современных AI-инструментов.

Разместить две основные кнопки с четкими акцентами:

Посмотреть проекты (оранжевый акцент).

Связаться (фиолетовый акцент).

В правой части Hero разместить визуальный элемент в стиле референса — фрагмент интерфейса или дашборда.

Обеспечить качественную адаптацию под мобильные устройства, сохранив читаемость и удобство взаимодействия. Остальное не трогай.
